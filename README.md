# FaceSwab2 · 로컬 얼굴 선택 합성

영상에서 드래그한 얼굴을 추적하고 JPEG/PNG에서 추출한 정면 얼굴을 합성하는 Windows 앱입니다.

안정 기준: **v0.1.0**. 이후 업데이트는 `feature/*`, 버그 수정은 `fix/*` 브랜치에서 관리하고 검증 후 `main`에 반영합니다. [변경 이력](CHANGELOG.md)과 [개발 인수인계](AGENT.md)를 참고하세요.

현재 작업 브랜치 `feature/natural-face-expression`은 **업데이트 1**입니다. 헤어 분리, 자연스러운 누끼 경계, 얼굴 전체의 표정 변형과 조명 보정을 추가했습니다. 다른 환경에서는 `setup_local.bat`를 다시 실행해 얼굴/헤어 분할 모델도 준비하세요.

**실행:** `run_gui.bat` 또는 `실행.bat` 더블클릭. 현재 PC에는 전용 Python, 가상환경, 얼굴 모델, FFmpeg를 설치했습니다.
다른 PC에서는 Python 3.12(Tk 포함)를 설치한 뒤 `setup_local.bat`를 실행하세요.

1. **영상 가져오기**: 비율을 유지하고 여백을 추가해 1280×720 / 30fps로 준비합니다.
2. **얼굴 이미지 가져오기**: JPEG/PNG에서 정면 얼굴 한 명을 인식하고 얼굴 윤곽 안쪽만 투명 PNG로 추출합니다.
3. **영상 얼굴 드래그**: 슬라이더로 시점을 고르고 바꿀 얼굴을 감쌉니다. 준비한 얼굴로 합성한 미리보기가 표시됩니다.
4. **합성 영상 저장**: MP4/H.264, AAC 48kHz 스테레오로 저장합니다. 원본이 무음이면 무음 스테레오 트랙을 만듭니다.

선택한 시점부터 합성됩니다. 영상 처음부터 합성하려면 첫 프레임에서 선택하세요. 추적이 중단되거나 장면이 바뀌면 해당 시점에서 다시 드래그해 선택 지점을 추가하세요. 선택 전과 추적 실패 구간은 원본을 유지하며, 완료 시 처리 통계와 `.report.json`을 제공합니다.

사람형 얼굴은 468개 기준점과 고정된 852개 삼각형으로 눈꺼풀·입술·볼·턱 움직임을 반영합니다. 눈동자와 입안은 영상의 모습을 보존하며 주변 얼굴은 업로드한 이미지로 변형합니다. 얼굴/헤어 분할과 다중 해상도 블렌딩으로 경계와 조명을 맞춥니다. 자동 인식이 어려운 캐릭터는 영역 추적으로 전환됩니다. **영역 모드**를 켜면 항상 선택 사각형에 얼굴을 맞추며 표정 변형이 적용되지 않습니다. 실제 적용된 모드는 완료 창과 보고서에 표시됩니다.

이 버전은 얼굴 누끼를 변형·합성하는 엔진입니다. 신원 임베딩을 사용하는 생성형 얼굴 교체 모델, 립싱크 생성, 모든 가림 상황에서의 복원을 구현한 것은 아닙니다. 실제 캐릭터 디자인·빠른 움직임·겹침에 따라 재선택이 필요합니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `face_swap_gui.py` → `src/local/gui.py` | Tkinter UI, 프레임 탐색, 드래그 선택, 누끼/합성 미리보기, 작업 큐 |
| `src/local/faces.py` | Tasks 얼굴 랜드마크, 정면 판정, 알파 누끼, 삼각형 변형과 색상 보정 |
| `src/local/matting.py` | 얼굴/헤어 분할, 곡선 윤곽, 경계 보정과 안쪽 페더링 |
| `src/local/expression.py` | 고정 얼굴 메시, 표정 반응 필터, 눈/입안 보존, 조명·경계 합성 |
| `src/local/tracking.py` | 선택 ROI의 CSRT 추적, optical flow 보정, 지역 얼굴 재검출, 추적 중단 판단 |
| `src/local/media.py` | 720p 변환, FFmpeg 실행/취소, 원본 오디오 처리 |
| `src/local/pipeline.py` | 프레임별 합성, 재선택 시점, 출력 검증, 원자적 MP4 교체 및 결과 보고서 |
| `scripts/local_swap.py` | GUI와 같은 엔진의 CLI |
| `scripts/setup_local.py` | 모델 다운로드 및 SHA256 검증, 실행 환경 진단 |
| `requirements-local.lock.txt` | 실제 설치·테스트한 전체 패키지 버전 |

기존 `src/infer`, `src/fomm`, `src/deepfacelab` 및 학습 스크립트는 보관되어 있지만 새 GUI에서 사용하지 않습니다. 이전 전체 학습 의존성은 `requirements-legacy.txt`로 분리했습니다.

기존 README에 명시된 교육/연구 목적 사용 조건은 유지됩니다.
